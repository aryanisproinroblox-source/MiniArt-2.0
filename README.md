## Overview

**MiniArt 2.0** is a compact, reasoning-optimised language model trained through supervised fine-tuning on a multi-model knowledge distillation dataset. It distils patterns from responses generated by leading frontier models — including GPT-5.5, Gemini 3.1 Pro, Grok 4, Claude Fable 5, Mythos 5, and others — into an efficient, locally-runnable model.

MiniArt 2.0 is purpose-built for:
- **On-device reasoning** — runs on consumer hardware without a GPU
- **Instruction following** — trained on diverse instruction-response pairs
- **Chain-of-thought tasks** — multi-step problem solving
- **Private deployments** — 100% local, no API calls required

## 🏋️ Training & Architecture

| Property | Value |
|:---|:---|
| **Fine-tuning Method** | LoRA (Low-Rank Adaptation), r=8, α=16 |
| **Target Modules** | `q_proj`, `v_proj` |
| **Training Steps** | 60 gradient steps |
| **Dataset** | Manusagents Multi-Model Distillation Dataset |
| **Dataset Size** | 600 samples |
| **Quantization** | Q4_K_M (4-bit, K-quant, medium quality) |
| **Format** | GGUF (llama.cpp compatible) |
| **Context Length** | 2048 tokens |

### Training Data

The model was fine-tuned on the **Manusagents GPT-5.5 / Gemini 3.1 Pro / Grok 4 / Claude Fable 5 / Mythos 5 / Qwen 3.7 Distillation Dataset**, which contains high-quality instruction-response pairs sampled from multiple frontier models.  
This approach transfers reasoning and instruction-following capabilities into a compact, efficient architecture.

## 🚀 Quickstart

### LM Studio
1. Download `miniart-2.0-q4_k_m.gguf`
2. Load the file in LM Studio
3. Set context length to 2048

### Ollama
```bash
# Download and run
ollama run hf.co/Dev4285/MiniArt-2.0
```

### llama.cpp
```bash
./llama-cli -m miniart-2.0-q4_k_m.gguf -n 512 --temp 0.7 -p "You are a helpful assistant."
```

### Python (via llama-cpp-python)
```python
from llama_cpp import Llama

llm = Llama(model_path="miniart-2.0-q4_k_m.gguf", n_ctx=2048)
output = llm("Q: What is the capital of France? A:", max_tokens=64)
print(output["choices"][0]["text"])
```

## ⚖️ Limitations

- Trained for 60 steps — reasoning improvement is real but modest relative to frontier models
- No vision or multimodal capabilities — text-only
- Best suited for lightweight on-device tasks rather than complex multi-turn dialogue
- GPQA Diamond score is near random chance, consistent with the model's compact size
